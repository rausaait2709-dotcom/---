# Математическая викторина

Интерактивный сайт-викторина в стиле телевизионного интеллектуального шоу для учащихся 9–10 классов. Весь интерфейс — на русском языке.

## Возможности

- **5 последовательных раундов × 6 вопросов = 30 вопросов** (источник: «Математическая викторина.docx»):
  1. Арифметика и вычисления
  2. Алгебра
  3. Геометрия
  4. Функции и тригонометрия
  5. Логика и математическая смекалка
- **Стартовый экран** с заголовком, подзаголовком, информацией (5 раундов / 30 вопросов / 30 секунд) и кнопкой «Начать викторину».
- **Экран-переход перед каждым раундом**: название, мотивация, кнопка «Готов! Начать раунд». Вопросы и таймер не запускаются до нажатия.
- **Настоящий таймер 30 секунд** на каждый вопрос: круговой индикатор, «красная» тревога при ≤10 сек, блокировка ответов по истечении, автопереход к следующему вопросу через 3 секунды после показа ответа.
- **Мгновенная проверка ответа**: зелёная подсветка верного варианта, красная — неверного, показ правильного ответа, блокировка повторного ответа.
- **Результаты после каждого раунда**: верные / неверные / без ответа, процент, цветная шкала, мотивационное сообщение, кнопка «Перейти к следующему раунду» (без автоперехода).
- **Итоговый экран**: общий счёт X из 30, процент, таблица по всем раундам со строкой ИТОГО, мотивационное сообщение по диапазонам баллов, кнопки «Пройти ещё раз» и «Посмотреть результаты по раундам».
- **Подробная статистика** по каждому из 30 вопросов со статусом (верно/неверно/без ответа) и правильным ответом.
- Звуковые эффекты (WebAudio, без файлов) с кнопкой отключения 🔊/🔇.
- Анимированный математический фон (π, ∑, √, формулы).
- Адаптивная вёрстка: компьютер, интерактивная доска (≥1400px), планшет, телефон.

## Структура проекта

| Файл | Назначение |
|---|---|
| `index.html` | Разметка всех экранов (старт, раунд, вопрос, результаты раунда, финал, детали) |
| `css/style.css` | Стили в стиле ТВ-шоу, адаптивность, анимации |
| `js/data.js` | **Данные викторины**: раунды, 30 вопросов, варианты, ключ ответов |
| `js/app.js` | Логика: состояние игры, таймер, подсчёт, экраны, звуки |

## Как редактировать вопросы (для преподавателя)

Всё находится в `js/data.js`. Каждый вопрос — объект:

```js
{ q: 'Текст вопроса', options: ['A', 'B', 'C', 'D'], correct: 1 } // 0=A, 1=B, 2=C, 3=D
```

- `q` поддерживает HTML-надстрочные индексы: `x<sup>2</sup>` → x².
- Правильные ответы до ответа участника на экран не выводятся.

> **Примечание:** вопрос 10 в исходном документе записан как «Чему равен 25?» — формулировка неполная. В коде используется «Чему равно 2⁵?» с правильным ответом D) 32 (см. комментарий в `js/data.js`). При необходимости измените формулировку и ключ в одном месте.

## Логика подсчёта

- Правильный ответ: +1 балл.
- Неверный ответ или истечение времени: 0 баллов.
- В финальной статистике «Неправильные» = выбранные неверно + без ответа; «Без ответа» показано отдельной строкой (X + Y + Z = 30).
- Повторное прохождение полностью сбрасывает счётчики, таймеры и результаты.

## Запуск

Открыть `index.html` в браузере (или опубликовать через Hosted Deploy). Зависимости — только Google Fonts (Montserrat), остальное автономно.

## Технические гарантии

- Единственный экземпляр таймера; `stop()` перед каждым запуском — нет дублирующих таймеров.
- Флаг `answered` — один вопрос даёт не более одного результата, даже при гонке «клик vs истечение времени».
- Проверено в браузере: консоль чистая; скриншоты стартового экрана, вопроса (десктоп и мобильный 390px), результатов раунда и финального экрана — вёрстка корректна.

## Демо-якоря для предпросмотра экранов

Для быстрой визуальной проверки: `index.html#demo-round`, `#demo-question`, `#demo-results`, `#demo-final`. На обычную игру не влияют.
